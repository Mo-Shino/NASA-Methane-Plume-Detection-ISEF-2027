# الدراسة الهندسية لمعمارية التنفيذ النهائية (SpectraPlume Full-Stack Architecture Blueprint)
**المشروع:** SpectraPlume — Autonomous Satellite Methane Intelligence (Regeneron ISEF 2027)  
**الهدف:** اختيار وتوثيق أفضل معمارية برمجية ولغات تنفيذ تجمع بين **الفخامة البصرية المطلقة (100% Custom Editorial Light UI)** و**الاعتمادية الصفرية بدون أخطاء (Zero-Error Single-Command Execution)** على الكمبيوتر والموبايل والسحابة المجانية.

## 2. المعمارية المعتمدة بالتفصيل: كيف سيعمل النظام؟

يعمل المشروع كمنظومة موحدة **(Unified Single-Origin Web Application)** عبر سيرفر بايثون واحد خفيف وفائق السرعة (`FastAPI + Uvicorn`):

```text
SpectraPlume Unified Web Server (Single Port: 8000 Local / 7860 Cloud)
│
├── 🧠 Backend Scientific Engine (Python 3.10+ / PyTorch / SciPy / Xarray)
│   ├── GET  /api/passes            --> بيانات المسحات المدارية الأربعة وحالاتها لحظياً
│   ├── POST /api/analyze           --> تشغيل الفيزياء + 3D-CNN + IME وإرجاع طبقات الخريطة الشفافة (Base64 PNG)
│   ├── POST /api/upload            --> فحص وتحليل أي ملف قمر صناعي (.nc / .h5) يرفعه المستخدم بالسحب والإفلات
│   ├── GET  /api/pixel-spectrum    --> استخراج طيف الـ 40 قناة لأي بكسل يضغط عليه المحكم لرسم بصمة الغاز مقابل الصخور
│   └── GET  /api/report/{scene_id} --> تصدير تقرير الطوارئ المعتمد (JSON + صفحة تقرير رسمية قابلة للطباعة PDF)
│
└── 🎨 Frontend Editorial Light SPA (Native HTML5 + Custom CSS Tokens + Vanilla ES6 JS)
    ├── web/index.html              --> الهيكل الدلالي النظيف ومكتبة أيقونات SpectraLine SVG المدمجة (0% Emojis)
    ├── web/css/spectraplume.css    --> نظام الألوان الفاتح (#F6F3EC / #12231A / #D4810B) والتجاوب للكمبيوتر والموبايل
    ├── web/js/app.js               --> إدارة الحالة، القوائم المنسدلة المخصصة، الرفع بالسحب والإفلات، ومفتاح الطبقات
    ├── web/js/map_controller.js    --> محرك الخرائط الفضائية الحية (Leaflet.js + Esri World Imagery + Plume/Noise Overlays)
    └── web/js/spectrum_chart.js    --> راسم المطياف التفاعلي الحي (2260/2315 nm CH4 Doublet vs 2335 nm CaCO3)
```

## 3. رحلة المستخدم والمحكّم في الواجهة الجديدة (Zero-Confusion User Flow)

### أ. على شاشة اللابتوب والكمبيوتر (وضع العرض الرئيسي في ISEF — Widescreen Console)
1. **الشريط العلوي الداكن (`#12231A`):** يحمل شعار `SpectraPlume` الرسمي (SVG)، و3 تبويبات واضحة بأيقونات فيكتور موحدة:
   * **`Live Radar & Map`** *(شاشة القيادة الرئيسية والخريطة الفضائية)*
   * **`Spectral Proof Lab`** *(معمل فحص البكسلات التفاعلي: غاز أم حجر جيري؟)*
   * **`Dispatch & Validation`** *(تقرير الطوارئ المعتمد + إحصائيات التحقق على 42 مسحاً من ناسا مطابقة للبوستر)*
   * زر علوي واضح **`Upload .nc Granule`** يفتح نافذة السحب والإفلات الأنيقة في أي وقت.
2. **القائمة اليسرى الذكية (`Orbital Scan Feed`):**
   * استبدال فكرة *"اختيار الخطأ من قائمة منسدلة"* بـ **4 بطاقات مسح مداري حية** (البحر الميت `Orbit 2222205`، خليج السويس، حوض بيرميان بتكساس، وجبل سيناء الجيري المميز بشارة خضراء `False Alarm Blocked`).
   * أسفلها درج تحكم أنيق (`Wind & AI Sensitivity`) لتعديل سرعة الرياح وعتبة الثقة بمنزلقات حية.
3. **مساحة العمل الرئيسية (واضحة من أول 3 ثوانٍ):**
   * **شريط الحكم اللحظي (Instant Verdict Banner):** يوضح بلغة بسيطة جداً هل المشهد **تسريب غاز فائق خطير** (باللون القرمزي الدافئ `#C0392B`) أم **إنذار صخري كاذب تم كشفه وإلغاؤه** (باللون الزمردي `#196B47`).
   * **4 بطاقات أرقام قياسية بيضاء (`#FFFFFF`):** معدل التسرب (`kg/h` و `Tons/h`)، كتلة السحابة (`IME`)، نسبة كبت الإنذارات الكاذبة، والخسارة الاقتصادية اليومية.
   * **الخريطة الفضائية التفاعلية (`Leaflet + Esri Satellite`):** تطير الكاميرا بنعومة عند اختيار أي مسح، وعليها شريط عائم لتبديل الطبقات لحظياً بدون إعادة تحميل:
     * `SpectraPlume AI`: يعرض السحابة الحقيقية المتدرجة بالعنبر والأحمر، أو علامة خضراء نظيفة على جبل سيناء.
     * `NASA Raw Filter`: يكشف البقع الصخرية البنفسجية الكاذبة (`243 بكسل`) التي خدعت الفلتر التقليدي فوق الجبل.
     * `Compare Both`: يضع الطبقتين معاً ليرى المحكم الفرق بعينه في ثانية واحدة!
   * **بطاقة الإثبات الطيفي المباشر بجانب الخريطة:** ترسم منحنى البكسل المختار وتوضح بصرياً وجود **نبضتي الميثان** (`2260 + 2315 nm`) أو **نبضة الصخور الكلسية الواحدة** (`2335 nm`)، مع إمكانية الضغط على أي نقطة على الصورة الطيفية لتغيير البكسل المفحوص حياً!

### ب. على الموبايل والتابلت (Responsive Mobile View عند مسح الـ QR Code)
* يتحول `Orbital Scan Feed` تلقائياً إلى شريط بطاقات أفقي قابل للسحب باللمس أعلى الصفحة.
* تنتظم البطاقات الإحصائية في شبكة `2×2` واضحة، وتأخذ الخريطة الفضائية ومنحنى الطيف العرض الكامل بلمس سلس بدون أي عناصر مقصوصة أو مزدحمة.

## 4. الاستضافة المجانية الدائمة والتشغيل المحلي

* **التشغيل المحلي على أي جهاز:** عبر نفس الملف [`run_demo.bat`](../run_demo.bat) أو `python run_demo.py` (يثبت `fastapi` و `uvicorn` تلقائياً إن لم يكونا موجودين، يتأكد من المشاهد الأربعة والأوزان، ويفتح المتصفح فوراً).
* **الرفع المجاني الدائم على السيرفر:** عبر ملف [`Dockerfile`](../Dockerfile) على منصة **Hugging Face Spaces (Docker SDK)** التي تمنحنا **`16 GB RAM` ومعالجين مجاناً مدى الحياة** برابط مباشر وسريع (`https://mo-shino-spectraplume.hf.space`) يعمل من أي كمبيوتر أو موبايل في العالم.
